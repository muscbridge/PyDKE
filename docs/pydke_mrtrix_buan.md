# Experimental pyDKE → MRtrix → DIPY BUAN bridge

This feature is a research prototype, not a validated clinical or group-analysis pipeline. It operates on a participant's existing pyDKE diffusion ODF SH, mask and scalar maps, tracks in native space with MRtrix, aligns to a streamline atlas with DIPY SLR, recognizes bundles with RecoBundles, and assigns native scalar samples to BUAN centroid disks. Source files are read only.

## Critical basis and orientation distinction

The current `pydesigner.tractography.odf.shbasis(..., "tournier")` differs by coefficient signs from DIPY's non-legacy Tournier/MRtrix3 basis. `pydke_to_mrtrix` implements the sign mapping and tests equality of evaluated functions at sampled directions. This is NOT the DIPY legacy-Descoteaux/MRtrix coefficient permutation. Historical outputs may have been generated by another version. The export path may also apply an axis flip; NIfTI affine, image storage, SH coordinate frame, gradient/tensor conventions, and all prior flips require independent physical-direction validation. Basis function equality alone does not establish anatomical correctness. The pipeline will only track when the operator explicitly attests `--coordinate-provenance-verified`. This switch is not evidence of validation. Validate against known-direction synthetic tensors and real anatomy, and establish the producing commit before use.

DKI diffusion ODFs are not CSD fiber ODFs. Their amplitude and angular behavior differ, can be negative, and `iFOD2` thresholds are not transferable from CSD. Determine cutoff and any rectification through a documented sensitivity study. The `--cutoff` option is deliberately mandatory; 0.1 is not an endorsed default. A finite/extreme-value gate (>1000) is a coarse guard, not a scientific quality certificate. Mask and all scalar inputs must share the native SH image grid. Inspect negative amplitudes and tractography anatomy. This module does not rectify ODFs automatically; see the separately provided `rectify-odf` command and validate its inputs and consequences before any use.

## Running

Use a pyDKE environment with compatible DIPY and MRtrix3 commands on PATH. Provide an atlas whole-brain tractogram and named atlas bundles. Preflight first:

```
pydke-buan --odf dki_odf.nii --mask brain_mask.nii --reference B0.nii \
  --metric dti_fa.nii --metric dki_mk.nii \
  --atlas-wholebrain whole_brain_MNI.trk --atlas-bundle CST_L.trk \
  --basis pydke-tournier --cutoff 0.1 --out pilot_preflight --preflight-only
```

After independent coordinate and provenance validation, use a **new output directory**, add `--coordinate-provenance-verified`, and set a justified `--cutoff`, `--count` and `--threads`. Non-deterministic tracking and chosen parameters must be accounted for in interpretation. Output includes input hashes, stage logs, transformed SH, tractograms and point-level disk assignments with separate simple unweighted disk means. These summaries are for QC, not the paper's linear mixed models or its inferential pipeline. Missing points remain missing; this is not an automatic complete BUAN statistical analysis. Nonlinear image warps are not used here. Check spatial overlays, streamline order, bundle orientation, anatomical plausibility, sampling support, and model-bundle coverage; inspect registration and extraction for each participant and bundle. Failures or incomplete bundles must not be presented as negative findings.

The Figshare 30-bundle atlas cited by DIPY is external data, not part of this repository: https://doi.org/10.6084/m9.figshare.12089652.v5. Preserve its license and citations. BUAN: https://doi.org/10.1038/s41598-020-74054-4.
